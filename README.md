# BLUE HOLE BIRTHDAY｜潜水冒险生日邀请函

一份专为手机设计的互动生日邀请函模板。访客会像接受游戏任务一样打开邀请函，经历下潜、接受生日委托、20 秒生日补给打捞、查看派对日程与地图，最后完成赴约登记。

无需安装框架或运行构建命令，项目只使用 HTML、CSS 和 JavaScript。所有个性化内容都集中在 `config.js` 一个文件里，改完双击 `index.html` 就能预览，不需要碰页面结构和样式。

> 🎂 [立即体验在线 Demo](https://mastrena.github.io/dave-diver-birthday-invitation/)

## 页面包含什么

- 手机端深海首页，含寿星姓名、日期、地点任务票
- 点击开始下潜，同时唤起背景音乐
- 随滚动变化的深度、氧气与补给分数 HUD（最深 420M）
- 长按接受生日委托
- 20 秒深海补给打捞小游戏：点蛋糕 +3、礼物 +2、气球 +1，误点海洋垃圾扣氧气，连击有加成，集满 8 件通关并解锁生日彩蛋
- 蓝洞小队来电轮播（DAVE、BANCHO、COBRA、DR. BACON）
- 生日限定菜单形式的当天流程、倒计时与礼物说明
- 地图导航入口，可换成自己的高德或百度地图链接
- 赴约登记演示：姓名、是否参加、同行人数、忌口过敏、声呐留言
- 底部快捷导航：任务 / 日程 / 地图 / 登记
- 适配 375px、390px、430px 手机宽度，并支持系统“减弱动态效果”设置

## 先说清楚：本模板不会收集信息

赴约登记是演示模式。访客填写的内容只保存在**访客自己设备的浏览器**里，不会发送到任何服务器，寿星也看不到名单。小游戏的最高分同样只存本地。

如需真实收集赴约信息，需要另外接入合规的表单或后端，并明确告知访客数据用途。请勿把数据库密码或密钥写在前端文件里。

## 三分钟开始

1. 点击 GitHub 页面右上方绿色 **Code** 按钮，选择 **Download ZIP**，下载并解压。
2. 用记事本、VS Code 或其他文本编辑器打开 `config.js`。
3. 依次替换 8 组内容：寿星信息 → 日期时间 → 地点与地图链接 → 主文案 → 当天流程 → 角色来电 → 随机祝福与彩蛋 → 背景音乐。
4. 保存后双击 `index.html` 预览。

`index.html`、`style.css`、`app.js` 都不需要修改。

## 和婚礼请柬版有什么不同

同一个作者的姊妹项目，结构相似，定位不同：

| | 婚礼请柬版 | 生日邀请函版 |
| --- | --- | --- |
| 需要修改的文件 | `index.html` + `app.js` | 只有 `config.js` |
| 中途互动 | 声呐探索、捕捉祝福鱼 | 20 秒补给打捞小游戏 |
| 登记字段 | 姓名、人数、住宿、留言 | 姓名、是否参加、人数、忌口、留言 |
| 分享教程 | 单独的 `SHARE.zh-CN.md` | 并入 `GUIDE.zh-CN.md` 第八节 |

婚礼请柬版：[mastrena/dave-diver-wedding-invitation](https://github.com/mastrena/dave-diver-wedding-invitation)

## 项目文件说明

```text
dave-diver-birthday-invitation/
├── config.js               # 只改这里：全部个性化内容
├── index.html              # 页面结构，一般不用改
├── style.css               # 视觉样式，一般不用改
├── app.js                  # 交互逻辑，一般不用改
├── assets/                 # 场景、角色、分享图（不含音乐文件）
├── GUIDE.zh-CN.md          # 零基础定制与部署教程
├── AI_SETUP_PROMPT.md      # 交给 AI 自动定制的提示词
├── COPYRIGHT_NOTICE.md     # 版权边界与降低风险建议
├── THIRD_PARTY_ASSETS.md   # 第三方素材清单
├── .nojekyll               # 让 GitHub Pages 原样发布静态文件
└── LICENSE                 # 原创代码 MIT 许可
```

背景音乐默认引用远程试听地址，音频文件不在仓库内；换成自己的音乐时，把文件放进 `assets/` 并在 `config.js` 里把 `musicUrl` 改成 `./assets/你的文件名.mp3`。

## 发布到 GitHub Pages

1. 点击仓库上方的 **Settings**。
2. 左侧点击 **Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 分支选择 `main`，目录选择 `/ (root)`，保存。

稍等约一分钟，网站通常会发布到：

```text
https://你的用户名.github.io/仓库名/
```

本仓库已按此方式发布在 https://mastrena.github.io/dave-diver-birthday-invitation/ 。

## 做好以后，怎么发给朋友

请发送**部署后的 HTTPS 网页地址**，不要发 `index.html` 文件、`localhost` 地址或 GitHub 仓库地址。

推荐顺序：

1. 先请 2～3 位朋友分别用苹果和安卓手机试开。
2. 检查首页、音乐、小游戏、地图、底部导航和赴约登记。
3. 再通过微信私聊或群聊发送链接，配一小段邀请文字。
4. 另外做一张带二维码的邀请图，作为朋友圈和现场指示牌的备用入口。

微信分享卡片说明、二维码制作、可直接复制的邀请文案，以及改完后朋友仍看到旧内容的解决办法，见 [定制教程第八节](./GUIDE.zh-CN.md#八把邀请函分享给亲朋好友)。
