## 关键约束（踩坑记录）

1. GitHub MCP 连接器**无创建仓库权限**：`mcp__github__create_repository` 返回 403 `Resource not accessible by integration`，只能改走 git/REST。
2. 二进制素材无法通过 MCP 上传：`push_files` / `create_or_update_file` 的 content 为纯文本，传图片会导致编码损坏，必须 git push。
3. 本机环境无 `gh` CLI、无 `~/.gitconfig`、无钥匙串凭据；commit 时用 `git -c user.name=... -c user.email=...` 内联指定作者（mastrena / mastrena@users.noreply.github.com）。
4. Fine-grained PAT 无法创建仓库，创建仓库需要 classic token 的 `repo` scope（用完即弃，不落盘；push 用 URL 内联 token，不写 remote，因此 .git 无凭证残留——已 grep 验证）。
